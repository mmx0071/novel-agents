# 正文常见雷区（硬约束）

连载实写中反复踩中的问题。**违反会被硬规则或一致性 P0 拦截**；专修/润色只能强化表达，不得改动下列事实板。

1. **章号元叙述**：除标题行 `# 第N章 …` 外，叙述/独白/对话禁止「第N章」「第八章」等连载章号。回溯用故事内时间/事件（「上次会面时」「那次事故之后」）。「第十三条…」等非章号专名除外。
2. **明确时间锚**：钟点 / 「还剩」「剩余」倒计时须**一条当前读数且单调**（只减不增）；具体读数宜少；回忆初始值须写「最初/原先」。禁止假回跳、两套并行当前值。
3. **时段词前进（易踩雷）**：凌晨 / 清晨 / 上午 / 中午 / 下午 / 傍晚 / 黄昏 / 夜里 / 夜晚 / 深夜 / 半夜 等会被系统当作**叙事时刻**扫描。
   - 全章选定一条当前时段线，只允许前进；回到更早时段必须交代跨日（翌日 / 天亮 / 过了一夜）。
   - **禁止**把时段词当修辞：当前是「凌晨」时，勿写「……的夜晚 / 夜里」作氛围；要用「黑暗 / 夜色 / 未亮的天」等非时段词。
   - 开写前先锁定本章当前时段（或「无时段词、只用钟点/倒计时」），全文不得无过渡混用冲突时段。
4. **伤势侧别/部位（首发锁定 / 症状承接）**：以 CanonContext【身体与能力状态板】与近章事实为准。
   - **首发或变更**：须写清谁 + 左/右或具体部位 + 伤情/行动限制；愈合、换手、侧别变更须有可见过程，禁止默默对调或挪位。
   - **承接（默认）**：已锁定的伤势**非必要不再点名左右**；用颤抖、握力发虚、指节发白、额角冷汗、不敢用力等神态/动作限制表现即可。中性「手/指尖」不算挪伤。
   - **必须分侧时**（递物、摘物、能力寄宿侧、对打分肢等）才写左右，且对齐状态板。
   - **对侧日常动作允许**：状态板锁左伤时，右手按内袋/取物等**健康侧日常动作**可写；**禁止**把伤口/撕裂/骨折/渗血等伤情写到对侧（同句点名对侧+伤情才会硬拦）。
   - **硬拦条件**：同句点名**反侧**并叠加伤情表述且无转移/愈合交代——不是「未重复写出侧别」，也不是裸「右手取物」。勿为提醒读者有伤而反复刷左右。
5. **能力寄宿/附着/载体**：以状态板为准；所在肢体、器物、印记点前后一致；更换须有可见转移过程，禁止默默换位。
6. **章间承接**：有【章间衔接】/前章钩子时，开篇必须直接接住，禁止另起无关场景让钩子蒸发。
7. **禁名与规范名**：只用名词表 / 注入名单中的规范名；禁止语料脸谱名与禁名表条目。
8. **修订须可核对**：改问题句时指令/补丁须带原文依据（location + quote 或等价锚点）；改完重检本表 1–9。
9. **作者旁白 / 章纲对读 / 纠错解说（绝对禁止）**：正文必须停留在故事内视角与场面；**禁止**把写作管线材料写进叙述。典型违例：
   - 点名或对读章纲/大纲/设定文档（「章纲里写的是…」「按大纲…」「设定上…」）——系统硬规则也会扫「章纲里」等泄露词
   - 用作者口吻消解矛盾或替读者释义（「不是往下走，是往下的意思」「这里其实是指…」）
   - 把空间/层级/机制讲成设计说明或讲义（「并非单向从 A 到 B，而是…；X 在中间、Y 在底层」这类说明书腔），而不是人物在当场看见、摸到、误判或说出口
   - 把「对白含义 vs 章纲措辞」的校准写进正文（那是写前对齐，不是叙述）
   
   **正确做法**：若章纲与对白需统一，在落笔前自行对齐后只写场面；机制只通过动作、感官、对话、误判自然露出。角色可以说自己的理解，但叙述者不得跳出故事当编辑/讲解员。

**不要**：把「略有压缩感 / 可补交代 / 剧情卡尚未收束」当成必须整章重写的理由；剧情卡跨章推进 ≠ 单章硬失败。
